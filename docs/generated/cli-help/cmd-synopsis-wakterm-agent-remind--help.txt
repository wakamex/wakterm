schedule messages that the mux sends to an agent later or on a repeat

Usage: wakterm agent remind <COMMAND>

Commands:
  add     schedule a message to an agent at a time, after a delay, or on a repeat
  list    list scheduled reminders, soonest first
  cancel  cancel a scheduled reminder
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
