# `ActivateOldestTabNeedingAttention`

Activates the oldest unseen completed agent response in a visible tab in the current window. Hidden tabs are skipped. It works through the same queue as [`ActivateNextTabNeedingAttention`](ActivateNextTabNeedingAttention.md) from the other end, so the responses that have waited longest are reviewed first.

This action has no default shortcut.
