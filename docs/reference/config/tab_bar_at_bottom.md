# `tab_bar_at_bottom = false`

When `tab_bar_at_bottom = true`, the tab bar will be rendered at the bottom of the window rather than the top of the window.

The default is `false`.

Press `Ctrl-Shift-A` to move the tab bar between the configured position and the opposite edge of the current window. The [`ToggleTabBarPosition`](../lua/keyassignment/ToggleTabBarPosition.md) key assignment can bind this action to another key.
