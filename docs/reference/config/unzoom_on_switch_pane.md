# `unzoom_on_switch_pane = true`

If set to `false`, the 
[`ActivatePaneDirection`](../lua/keyassignment/ActivatePaneDirection.md) command
will have no effect if the active pane is zoomed. 

If `true`, the active pane will be unzoomed first and then switched.

See also: [`TogglePaneZoomState`](../lua/keyassignment/TogglePaneZoomState.md)
