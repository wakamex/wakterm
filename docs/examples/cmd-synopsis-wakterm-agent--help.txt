Start and interact with agents

Usage: wakterm agent <COMMAND>

Commands:
  start           start an agent harness in the current pane, a split, a new tab, or a new window
  launch          launch an agent through a mux-owned transport
  adopt           adopt an existing pane as an agent
  adopt-detected  promote a detected harness pane into persistent agent metadata
  list            list adopted and detected agent panes
  watch           stream latest observer-backed harness messages for adopted and detected agent panes
  inspect         inspect a single adopted or detected agent by name or id
  output          read experimental normalized agent output for shadow comparison
  events          read durable normalized Agent API events
  capabilities    print the versioned Wakterm Agent API capabilities
  catalog         print the narrow Wakterm Agent API catalog
  admit           atomically admit and submit an agent prompt
  send            send a message to an agent pane
  request         inspect and stream durable agent return requests
  interrupt       interrupt a native harness turn
  set             attach agent metadata to a pane
  clear           remove agent metadata from a pane
  help            Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
