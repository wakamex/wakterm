wakterm bundles the [JetBrains Mono](https://www.jetbrains.com/lp/mono/) 2.304, [Roboto](https://github.com/googlefonts/roboto-3-classic) 3.016 and [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) 2.057 fonts, which are distributed under the [SIL Open Font License (OFL) 1.1](https://openfontlicense.org/). Its text is in `assets/fonts/LICENSE_OFL.txt`.

wakterm bundles Symbols Nerd Font Mono 3.5.1 from [Nerd Fonts](https://www.nerdfonts.com/), whose own files are under the MIT license in `assets/fonts/LICENSE_NERD_FONTS.txt`. The font combines icon sets under these licenses:

- Pomicons and Weather Icons: OFL 1.1, in `assets/fonts/LICENSE_OFL.txt`.
- Material Design Icons: Apache License 2.0, in `assets/fonts/LICENSE_APACHE.txt`.
- Codicons, copyright Microsoft Corporation, and Font Awesome, copyright Fonticons, Inc.: [Creative Commons Attribution 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
- Devicons, Font Awesome Extension, IEC Power Symbols, Octicons and the Seti-UI icons: MIT.
- Powerline Extra Symbols: MIT, in `assets/fonts/LICENSE_POWERLINE_EXTRA.txt`.
- Font Logos: [The Unlicense](https://unlicense.org/).
- Powerline Symbols: a free license.

[Nerd Fonts' license audit](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/license-audit.md) lists the source of each set.

The bundled fonts are stored in the [Web Open Font Format 2 (WOFF2)](https://www.w3.org/TR/WOFF2/), converted without changes from the upstream TrueType releases.
