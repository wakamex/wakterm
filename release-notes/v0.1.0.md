wakterm is a GPU-accelerated cross-platform terminal emulator and multiplexer built on [WezTerm](https://github.com/wezterm/wezterm) for working with terminal coding agents ([Claude Code](https://claude.com/product/claude-code), [Codex](https://github.com/openai/codex), [Gemini CLI](https://github.com/google-gemini/gemini-cli), [OpenCode](https://opencode.ai/), [ZCode](https://docs.z.ai/devpack/tool/zcode), and [Antigravity CLI (agy)](https://antigravity.google/)) alongside shells, editors, and development tools. This is its first release.

## Highlights

- Native coding agent integration: automatic detection and adoption of running agent sessions, per-tab harness icons, completion and attention badges, tab dimming for working agents (`agent_tab_dim_working`, on by default) and reviewed replies (`agent_tab_dim_reviewed`, optional), a jump to the newest unread agent reply, including in hidden tabs (`ActivateNextTabNeedingAttention`, unbound by default), live activity-order tab sorting (`ToggleTabActivityOrder`, `Ctrl-Shift-B` on Linux and Windows, `Cmd-Shift-B` on macOS), and opt-in idle agent process freezing (`agent_idle_freeze`, default false, on Linux and Windows).
- Session persistence and recovery: workspace layout save and restore across multiplexer restarts, exact conversation resumption for supported harnesses when the multiplexer restarts, and managed Codex app-server sessions that share a background server across panes.
- Agent API and CLI (`wakterm agent`): structured session listing, event streams, output reading, draft-safe and keyboard-safe prompt admission with `--return-final` correlation, interactive approval and question resolution (`wakterm agent approval`, including Claude Code confirmation menus `claude_menu.v1` and `Session paused` fallback menus), caller resolution (`wakterm agent caller`), and persistent scheduled reminders (`wakterm agent remind`).
- Tab management and navigation: hidden (parked) tabs that keep background processes alive off the tab bar, fuzzy tab navigator (`ShowTabNavigator`, `Alt-E` on Linux and Windows, `Cmd-E` on macOS) with `Ctrl-H` inside the navigator to hide or unhide a tab, `Alt-1..9` tab switching on Linux and Windows (`alt_tab_shortcuts`, on by default alongside the `Ctrl-Shift` equivalents) and `Cmd-1..9` on macOS, per-tab colors, and smooth title shrinking (`tab_titles_shrink_to_fit`).
- Multi-client multiplexer synchronization: atomic split resize and tab reorder requests, explicit client origin tracking without timing heuristics, and client-local view state.
- Bundled [Web Open Font Format 2 (WOFF2)](https://www.w3.org/TR/WOFF2/) fonts: [JetBrains Mono](https://www.jetbrains.com/lp/mono/) 2.304, [Roboto](https://github.com/googlefonts/roboto-3-classic) 3.016, [Noto Color Emoji](https://github.com/googlefonts/noto-emoji) 2.057, and [Nerd Fonts](https://www.nerdfonts.com/) Symbols Nerd Font Mono 3.5.1.

## Package managers

After the release assets are published, install on macOS with [Homebrew](https://brew.sh/):

```sh
brew tap wakamex/tap
brew install --cask wakamex/tap/wakterm
```

Or on Windows with [Scoop](https://scoop.sh/):

```powershell
scoop bucket add wakamex https://github.com/wakamex/scoop-bucket
scoop install wakamex/wakterm
```

## Verifying a download

Every release asset is attested by the shared release workflow. Verify any downloaded file with [GitHub CLI](https://cli.github.com/):

```sh
gh attestation verify ASSET --repo wakamex/wakterm \
  --signer-workflow wakamex/release-actions/.github/workflows/binary-release.yml
gh release verify-asset v0.1.0 ASSET --repo wakamex/wakterm
```
